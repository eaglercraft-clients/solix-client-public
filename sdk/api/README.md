# SolixClient plugin API reference

> Generated by `tools/gen-sdk.js` from the client's plugin host. API **1.7**. Do not edit by hand.

Everything hangs off the injected `solix` object. Types: [`../types/solix.d.ts`](../types/solix.d.ts).

## `solix` members

| Member | Description |
| --- | --- |
| `solix.apiVersion` | Major API version (`1`). |
| `solix.apiMinor` | Minor API version (`5` = 1.5). Undefined on very old clients: test `(solix.apiMinor \|\| 0) >= 3`. |
| `solix.manifest` | `{id, name, version, author, apiVersion, hooks}` of this plugin |
| `solix.on(event, fn)` | Subscribe to an event (table below). Returns `solix`. |
| `solix.log()` | Write to the client log (browser console), tagged with your plugin id, and to the last-50-lines log kept per plugin. `console.log` does the same. |
| `solix.notify(text)` | Show a small Solix toast (max 160 chars). |
| `solix.player` | Your own player (`null` outside a world): position, facing, health, food, xp, dimension, held items, armor, effects. Fresh copy per read. |
| `solix.stats` | `{fps, ping, tps, cps, memory}`. `tps` is estimated from the server's time-update packets (about one per second; `20` in singleplayer, `null` outside a world). `cps` = your left clicks in the last second. `memory` = `{usedMB, totalMB, limitMB}` of the JS heap where the browser exposes it (Chromium), else `null`. |
| `solix.client` | `{fps, ping, server, singleplayer, inGame, screen, time, version}`. |
| `solix.theme` | Active theme colours `{id, accent, accentBright, accentDim, text, textMuted}` as hex strings. |
| `solix.settings.bool(id, label, d, desc)` | Toggle setting. |
| `solix.settings.slider(id, label, min, max, step, d, desc)` | Numeric slider. |
| `solix.settings.choice(id, label, options, d, desc)` | Dropdown; value is the index. |
| `solix.settings.color(id, label, d, desc)` | Colour picker; value is ARGB int. |
| `solix.settings.keybind(id, label, keyName, desc)` | Rebindable key; fires `keybind` / `keybindRelease`. |
| `solix.settings.text(id, label, d, desc)` | A text field (max 64 chars) in the plugin panel. `get()` returns the string. |
| `solix.settings.get(id)` | Current value of a setting. |
| `solix.hud.register(el)` | Register a draggable HUD element `{id, name, width, height, x, y, render(g, ctx)}`. Hook `hud`. |
| `solix.hud.replace(id, fn, o)` | &nbsp; |
| `solix.hud.restore(id)` | &nbsp; |
| `solix.hud.elements` | &nbsp; |
| `solix.hud.overlay(fn)` | A full-screen layer drawn under the HUD elements, at the canvas origin. `fn(g, ctx)` gets `ctx.width` / `ctx.height` equal to the whole screen. Use it for vignettes, hit flashes and so on. It needs the `hud` hook, is not shown in the HUD editor, and is skipped while editing. |
| `solix.crosshair.hideVanilla(on)` | Hide the vanilla crosshair while your plugin is enabled (the attack indicator stays). Needs the `crosshair` hook. It is restored automatically when the plugin is disabled or errors out, and re-applied when it is enabled again. |
| `solix.menu.addButton(b)` | Add a button `{id, label, location: main\|pause, icon, onClick}`. Hook `menu`. |
| `solix.themes.register(t)` | Add a theme to Appearance `{id, name, extends?, accent, glassTint, glassStrength, background, description}`. Hook `themes`. See ../themes/. |
| `solix.view.setZoom(f)` | FOV multiplier, clamped to 0.15..1. Changes are smoothed, ignored while a screen is open, and reset when you're disabled. |
| `solix.view.setFovClamp(min, max)` | Clamp the final in-game FOV to `min..max` degrees (1..179) after every vanilla effect (sprint, speed, bow, water). Pass `0`/`null` for one side to leave it open; `setFovClamp()` clears it. Zoom (`setZoom` and the zoom key) still applies on top. |
| `solix.view.hurtCamScale(v)` | Damage camera tilt, 0..1 (default 1). `0` = no tilt. |
| `solix.view.freelook(on)` | While `true`, the mouse orbits a third-person camera around you; your real yaw/pitch, and so your movement direction, stay locked. `false` snaps back to your previous view. Pair it with a `solix.settings.keybind` and the `keybind` / `keybindRelease` events. Released automatically when your plugin is disabled. |
| `solix.view.dynamicFovScale` | Read/write number, 0..1 (default 1). Scales the vanilla "dynamic" FOV change from sprinting, speed/slowness and bow drawing. `0` = no FOV change at all (No Dynamic FOV). Set it: `solix.view.dynamicFovScale = 0`. |
| `solix.render.fireScale(v)` | First-person fire overlay size, 0..1 (default 1). It shrinks toward the bottom of the screen; `0` hides it. |
| `solix.render.offhandScale(v)` | First-person offhand item size, 0..1 (default 1). `0` hides it. Only your own view; others see nothing different. |
| `solix.render.hitColor(c)` | Tint of the red hurt flash on entities, e.g. `"#80FFFFFF"`. Alpha scales the strength (`FF` = vanilla strength). `hitColor(null)` restores vanilla red. |
| `solix.render.post.set(passes)` | Install your chain: `[{name, fragment: "shaders/grade.fsh", scale}]` (`fragment` = a file in your pack) or `{source: "glsl..."}` inline; a plain string is a fragment path. Up to 8 passes, 64 KB each. Passes run in order on the finished world image (after the hand, before the HUD/GUI); the last pass writes the screen. `scale` (0.0625..1) renders that pass at a fraction of the screen size (cheap blur chains). Replaces your previous chain; chains of several plugins run one after another in enable order. |
| `solix.render.post.uniform(name, v)` | Set a uniform on every pass of your chain: a number, `[x, y]`, `[x, y, z]`, `[x, y, z, w]`, a boolean (sent as int), or `{int: true, value: [..]}` for `int`/`ivecN`. Values persist until the chain is replaced. |
| `solix.render.post.uniforms(o)` | Same, for every key of `obj`. Handy for presets: `uniforms({Saturation: 1.2, ENABLE_VIGNETTE: true})`. |
| `solix.render.post.clear()` | Remove your chain. Also happens when the plugin is disabled. |
| `solix.render.hitboxes(o)` | Draw entity hitbox outlines, only for entities you can actually see: invisible entities are skipped, and so is any entity whose box centre and all 8 corners are hidden behind blocks from the camera (and anything over 128 blocks away). Defaults: `players: true, mobs: true, items: false`, colour white. `hitboxes({enabled: false})` turns it off. F3+B (vanilla hitboxes) overrides it. |
| `solix.combat.lastTarget` | The living entity you last hit, while it's alive, loaded and the hit was under 5 s ago, else `null`: `{name, type, health, maxHealth, armor, distance}` (`armor` = armour points 0..20). |
| `solix.world.predictBreak(o)` | Opt-in client-side prediction. With `crystals: true`, an end crystal you hit is hidden at once instead of waiting for the server; if the server hasn't removed it within 1 s it comes back. `predictBreak({})` turns it off. `anchors` is accepted but currently does nothing: the 1.14.4 client has no respawn anchor block, so there is nothing to predict. |
| `solix.options.setToggleSprint(on)` | Turns on the vanilla-style toggle-sprint behaviour: tapping the sprint key latches it. It never sprints on its own. |
| `solix.screenshot()` | Take a normal screenshot at the next tick. Needs the `screenshot` hook. |
| `solix.gui.setScale(n)` | Fractional GUI scale, `0.5..4` in `0.25` steps (rounded). It is clamped so the GUI is never smaller than 320x240 GUI pixels; `setScale(0)` / `setScale("auto")` returns to the vanilla Video setting. If several plugins set it, the most recent live one wins. Reset when your plugin is disabled. |
| `solix.gui.getScale()` | The scale in effect right now (may be fractional, may differ from what you asked for after clamping). |
| `solix.gui.width` | Current GUI width in GUI pixels. |
| `solix.gui.height` | Current GUI height in GUI pixels. |
| `solix.gui.screen` | The open screen's class name, like `solix.client.screen`. |
| `solix.gui.layout(ids, spec)` | Re-lay out container screens. `ids`: a screen id, a class name, an array of them, or `"*"` for every container screen. Returns `{remove()}`. Re-applied every time a screen opens or resizes (and on creative tab switches). Several layouts for one screen merge in enable order (later wins per field). |
| `solix.gui.onDraw(phase, fn, ids)` | Draw before / after any screen (menus, chat, options, containers). `ids` defaults to `"any"`. Returns `{remove()}`. |
| `solix.gui.highlight(o)` | The same highlight colours for every container screen; a layout's own colours win. |
| `solix.gui.itemRenderer(fn, o)` | &nbsp; |
| `solix.gui.clearLayouts()` | Drop all of your layouts, draw hooks and highlights. |
| `solix.chat.input.mask(rule)` | While the chat box text starts with one of `prefixes` (e.g. `["/login", "/l", "/register", "/reg", "/changepassword"]`), every non-space character after the command is drawn as `char` (default `*`). Display only: the text that is sent is unchanged. `mask(null)` clears. Rules are dropped when the plugin is disabled, so set them in `solix.on("enable", ...)`. A function form is not supported (rules run client-side, no per-keystroke JS). |
| `solix.vault.save(host)` | Opens a client-drawn "Save login for <host>" dialog (default host = the server you are on). The password goes into the client's vault, never to the plugin. |
| `solix.vault.has(host)` | Which hosts have a saved login (host names only). |
| `solix.vault.hosts()` | &nbsp; |
| `solix.vault.list()` | &nbsp; |
| `solix.vault.remove(host)` | Forget one saved login. |
| `solix.vault.autoLogin(o)` | &nbsp; |
| `solix.resources.declared` | The kinds from your `plugin.json` `resources`. |
| `solix.resources.reload()` | Ask the client to reload resources (once, on the next tick). Toggling the plugin already does this. |
| `solix.fonts.list()` | &nbsp; |
| `solix.fonts.has(n)` | &nbsp; |
| `solix.util.textWidth(str, size, font)` | Measure text in the Solix fonts. |
| `solix.util.textHeight(size, font)` | (1.2) Cap height of the Solix font at that size. `g.text` centres the caps on `y`. |
| `solix.util.color(c, def)` | Parse `"#RGB"`, `"#RRGGBB"`, `"#AARRGGBB"` or a number into a signed ARGB int. |
| `solix.util.argb(a, r, g, b)` | (1.1) Build a colour from 0..255 channels. Returns a `"#AARRGGBB"` string, so `a = 0` really is transparent. |
| `solix.util.withAlpha(c, a)` | (1.1) The same colour `c` with alpha `a` (0..1), as a `"#AARRGGBB"` string. Use it for fades. |

## Draw context `g` (HUD `render(g, ctx)` and overlays)

| Member | Description |
| --- | --- |
| `g.rect(x, y, w, h, c)` | filled rectangle |
| `g.roundRect(x, y, w, h, r, c)` | rounded rectangle |
| `g.gradient(x, y, w, h, top, bottom, angle)` | vertical gradient |
| `g.polygon(pts, c)` | filled polygon, convex or concave (no holes) |
| `g.polyline(pts, width, c, closed)` | stroked path with round joins |
| `g.arc(cx, cy, r, a0, a1, width, c)` | stroked arc, radians, clockwise on screen |
| `g.pie(cx, cy, r, a0, a1, c, inner)` | filled sector, or a ring segment when `inner > 0` |
| `g.ring(cx, cy, r, width, c)` | full circle outline |
| `g.shape(x, y, w, h, o)` | rounded or angled (`cut: true`) rect with fill/gradient and outline |
| `g.svg(d, x, y, size, c, o)` | SVG path icon (`d` attribute, any path incl. holes); rasterised by the browser once per size and cached; `stroke > 0` strokes instead of fills |
| `g.image(path, x, y, w, h, o)` | a PNG from your pack at any resolution |
| `g.panel(x, y, w, h, opts)` | a Solix glass panel. `accent: true` gives the theme-coloured selected look. |
| `g.line(x0, y0, x1, y1, t, c)` | line |
| `g.circle(cx, cy, r, c)` | filled circle |
| `g.text(str, x, y, opts)` | `font`: `medium` (default), `semibold`, `display`. `align`: `left`, `center`, `right` (x is the anchor). **`y` is the vertical centre of the capitals**, not the top: the caps span `y - h/2 .. y + h/2` with `h = g.font.height(size, font)`, and descenders hang below. To centre a line in a box of height `H`, pass `y = top + H / 2`. |
| `g.textWidth(str, size, font)` | measure |
| `g.font` | (1.2) `{width(str, size, font), height(size, font)}` text metrics. |
| `g.icon(name, x, y, size, c)` | a Solix UI icon (list below) |
| `g.glass(x, y, w, h, o)` | Frosted panel: a blurred copy of what is behind it (world + screen tint). The blur is taken once per frame, by the first glass panel, at 1/4..1/16 resolution, and shared by every panel after it; so `blur` (0.25..2) only counts on that first panel. `dim` 0..1 darkens it (0.8), `tint` is laid on top, `cut` uses the Solix cut corners. Also works in HUD elements. Falls back to flat translucent glass when the player has glass turned off. |
| `g.item(slot, x, y, size)` | draws your own item: `mainhand`, `offhand`, `head`, `chest`, `legs`, `feet` |

## Events

| Event | Args | Hook | When |
| --- | --- | --- | --- |
| `enable` | none | none | The plugin was turned on, including at boot. |
| `disable` | none | none | The plugin was turned off, removed or auto-disabled. Undo things here. |
| `tick` | `state` | `tick` | Every client tick (20/s). `state` = `{client, player, theme}`. |
| `key` | `code, name` | `input` | A key was pressed in game. Never fires while a screen or chat is open. `name` is like `"W"`, `"F6"`, `"LEFT_SHIFT"`. |
| `mouse` | `button, down` | `input` | A mouse button went down or up in game (0 = left, 1 = right, 2 = middle). |
| `keybind` | `settingId` | none | The key bound to one of your `keybind` settings was pressed. |
| `keybindRelease` | `settingId` | none | ...and released. |
| `chat` | `text` | `chat` | A chat line arrived (plain text, max 512 chars). |
| `screenOpen` | `name` | `screen` | A screen opened (`"none"` when it closed). |
| `serverJoin` | `address` | `server` | Entered a world or server. Singleplayer gives `""`. |
| `serverLeave` | none | `server` | Left it. |
| `settingChange` | `id, value` | none | The player changed one of your settings. |
| `attack` | `hit, targetName` | `combat` | (1.3) You swung: `true` + the entity's name when it connected, `false` + `null` on a miss. |

## Hooks

Declare these in `plugin.json` `hooks`. Calls without the hook are refused and logged.

| Hook | Shown to the player as |
| --- | --- |
| `tick` | Run code every game tick (20 times a second) |
| `hud` | Draw elements on the in-game HUD |
| `input` | See your key presses and mouse clicks while playing (never while typing in chat or menus) |
| `chat` | Read incoming chat messages |
| `screen` | Know which menu is open |
| `server` | Know which server you join and leave |
| `menu` | Add buttons to the main or pause menu |
| `themes` | Add themes to Appearance |
| `zoom` | Zoom your view in (lower the FOV) |
| `sprint` | Turn the toggle-sprint option on or off |
| `screenshot` | Take screenshots |
| `crosshair` | Hide the vanilla crosshair while enabled (to draw its own) (1.1) |
| `combat` | Know when you take damage (1.1), land or miss a hit, and see your last target (1.3) |
| `fov` | Change your FOV limits and the sprint/speed FOV effect (1.3) |
| `visuals` | Change visuals: fire/offhand size, hurt camera tilt, hit colour, entity hitboxes (1.3) |
| `freelook` | Look around in third person without turning your player (1.3) |
| `predict` | Hide end crystals you hit before the server confirms (1.3) |
| `settings` | Change client settings (GUI scale) (1.4) |
| `resources` | Replace game textures, GUI sprites, fonts, sounds or language text while enabled (1.4, added automatically when `resources` is declared) |
| `shaders` | Run shader programs on the game image (post-processing, sky, water) (1.5) |
| `gui` | Re-lay out and draw over game screens (inventory, containers, menus) (1.6) |
| `vault` | Ask SolixClient to save your server login and log you in (the plugin never sees the password) (1.6) |

## Pack format

### `.solixplugin` (zip)

```
my-plugin.solixplugin
├── plugin.json
├── main.js            # entry (can be several files)
└── bg.jpg             # optional assets (theme backgrounds)
```

`plugin.json`:

```json
{
  "id": "my-plugin",
  "name": "My Plugin",
  "version": "1.0.0",
  "author": "you",
  "description": "What it does, shown in the Plugins screen and on install.",
  "apiVersion": 1,
  "entry": "main.js",
  "hooks": ["hud", "input"]
}
```

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | `a-z 0-9 . _ -`, max 40 chars, unique. Installing a pack with the same id replaces the old one. |
| `name`, `version`, `author`, `description` | no | Shown in the UI. |
| `apiVersion` | yes | `1` for now. Packs that need a newer API than the client has are refused. |
| `entry` | yes* | One file name, or an array of names that are evaluated in order. *Optional for resources-only or font-only packs (a `resources` / `font` declaration and no JS). |
| `hooks` | no | What the plugin uses (see [Hooks](#hooks)). `permissions` is accepted as an alias. |
| `icon`, `category` | no | Reserved for the UI. |
| `resources` | no | (1.4) Ship an `assets/` folder that overlays the game's assets, see [Resource overrides](#resource-overrides-14). `true`/`"all"`, an array of kinds, or `{"kinds": [...], "priority": 0}`. |

Limits:
- the pack can be at most 16 MB, and at most 32 MB once unpacked
- at most 64 files (4096 when the pack declares `resources`)
- at most 1 MB of JavaScript in total
- no absolute paths or `..` in file names

### Single `.js` file

For quick plugins you can skip the zip. Put the metadata in a header comment:

```js
// ==SolixPlugin==
// @id          toggle-sprint
// @name        Toggle Sprint
// @version     1.0.0
// @author      you
// @description Tap sprint once to keep sprinting.
// @api         1
// @hooks       sprint, hud
// ==/SolixPlugin==

solix.on("enable", function () { solix.options.setToggleSprint(true); });
```

## Settings

Declare settings at load time. They appear automatically in your plugin's panel on the Plugins screen, styled like the
rest of Solix, and they persist per plugin. Each call returns a handle with `.get()`.

```js
solix.settings.bool(id, label, default, description?)
solix.settings.slider(id, label, min, max, step, default, description?)
solix.settings.choice(id, label, ["A", "B", "C"], defaultIndex, description?)   // value is the index
solix.settings.color(id, label, "#FF4FB8", description?)                        // value is an ARGB int
solix.settings.keybind(id, label, "V", description?)                            // value is a key name
solix.settings.get(id)
```

Keybind names: `A`-`Z`, `0`-`9`, `F1`-`F25`, `SPACE`, `LEFT_SHIFT`, `RIGHT_SHIFT`, `LEFT_CONTROL`, `RIGHT_CONTROL`,
`LEFT_ALT`, `RIGHT_ALT`, `TAB`, `CAPS_LOCK`, `NONE`, and so on. The player can rebind the key in the panel, and you get
`keybind` / `keybindRelease` events for it.

## HUD elements (`hud` hook)

```js
solix.hud.register({ id, name, width, height, x, y, render(g, ctx) })
```

- `x`, `y` set the default position as fractions of free space (0 = left/top, 1 = right/bottom). Once the player drags
  the element in the HUD editor, their position wins.
- `render` runs every frame while in game, hidden with F3, and in the HUD editor. Return `{width, height}` to resize
  the element.
- `ctx` = `{width, height, editing, state}`. `editing` is true in the HUD editor, so draw a preview if you'd otherwise
  be empty. `state.input` = `{forward, back, left, right, jump, sneak, sprint, attack, use}`, which tells you whether
  those keys are held this frame.

The `g` draw context. All methods chain. Colours take any format `util.color` accepts.

| Method | |
| --- | --- |
| `g.rect(x, y, w, h, color)` | filled rectangle |
| `g.roundRect(x, y, w, h, radius, color)` | rounded rectangle |
| `g.gradient(x, y, w, h, topColor, bottomColor)` | vertical gradient |
| `g.panel(x, y, w, h, {radius, alpha, accent})` | a Solix glass panel. `accent: true` gives the theme-coloured selected look. |
| `g.line(x0, y0, x1, y1, thickness, color)` | line |
| `g.circle(cx, cy, r, color)` | filled circle |
| `g.text(str, x, y, {size, color, font, align, shadow})` | `font`: `medium` (default), `semibold`, `display`. `align`: `left`, `center`, `right` (x is the anchor). **`y` is the vertical centre of the capitals**, not the top: the caps span `y - h/2 .. y + h/2` with `h = g.font.height(size, font)`, and descenders hang below. To centre a line in a box of height `H`, pass `y = top + H / 2`. |
| `g.textWidth(str, size, font)` | measure |
| `g.font.width(str, size, font)` / `g.font.height(size, font)` | (1.2) Text width and cap height in HUD units, matching the renderer. The same object is `ctx.font` in `render(g, ctx)` and overlay callbacks. |
| `g.icon(name, x, y, size, color)` | a Solix UI icon (list below) |
| `g.item(slot, x, y, size)` | draws your own item: `mainhand`, `offhand`, `head`, `chest`, `legs`, `feet` |

Icons:


## Menu buttons (`menu` hook)

```js
solix.menu.addButton({ id: "shot", label: "Screenshot", location: "pause", icon: "eye", onClick: function () { ... } })
```

`location` is `"main"` (the main menu shows up to 3 plugin buttons) or `"pause"`. Labels are cut off at 24 characters.

## Themes (`themes` hook)

```js
solix.themes.register({
  id: "vaporwave", name: "Vaporwave",
  accent: "#FF4FB8",            // drives every gold/accent colour in the UI
  glassTint: "#3A1460", glassStrength: 0.6,
  background: "bg.jpg",         // an image inside your pack (jpg/png/webp), shown behind the menus
  description: "Neon grid, striped sun"
})
```

Add `extends: "solix-default"` (or any built-in id like `tokyo_night`) to inherit: keys you leave out fall through to
the parent at runtime, so client updates to the parent propagate. See the public SDK `sdk/themes/`.

Pack themes show up in **Settings > Appearance** next to the built-in ones while the plugin is enabled. If the player
had picked a pack theme and the plugin goes away, the client falls back to the default theme.

## Colours

Every `color` argument takes a string (`"#RGB"`, `"#RRGGBB"`, `"#AARRGGBB"`) or a number. **Numbers are ambiguous**: a
number from `0` to `0xFFFFFF` is read as an *opaque* `0xRRGGBB` (so `0x000000` is black and `0x00FF0000` is opaque red),
which keeps older packs that pass `0xD2AE62` working. Larger and negative numbers (`0x80FF0000`, `(a << 24 | rgb) | 0`
with `a >= 1`) are taken as ARGB as given. Alpha 0 can't be expressed as a number, so for transparency and fades use the
string form: `"#00000000"`, `"#80FF0000"`, or `solix.util.withAlpha(c, a)` / `solix.util.argb(a, r, g, b)` (1.1). Pass those strings straight to the draw call; converting them with `solix.util.color` first gives a number, and alpha 0 is lost again.

## API 1.1 additions

These are backward compatible: old packs keep working unchanged, and a 1.1 pack can feature-test with
`(solix.apiMinor || 0) >= 1`.

| Addition | Details |
| --- | --- |
| HUD ctx screen size | The HUD `render(g, ctx)` ctx now also has `screenWidth` / `screenHeight` (the whole HUD canvas, in HUD units, the same units you draw in) and `guiWidth` / `guiHeight` (the vanilla scaled GUI size). Centre something with `x = (ctx.screenWidth - w) / 2` and then position the element at `x: 0.5, y: 0.5`. |
| `solix.hud.overlay(fn)` | A full-screen layer drawn under the HUD elements, at the canvas origin. `fn(g, ctx)` gets `ctx.width` / `ctx.height` equal to the whole screen. Use it for vignettes, hit flashes and so on. It needs the `hud` hook, is not shown in the HUD editor, and is skipped while editing. |
| `solix.crosshair.hideVanilla(on)` | Hide the vanilla crosshair while your plugin is enabled (the attack indicator stays). Needs the `crosshair` hook. It is restored automatically when the plugin is disabled or errors out, and re-applied when it is enabled again. |
| `damage` event | `solix.on("damage", (amount, newHealth) => ...)`: your own player lost health. It is computed from your own health between ticks, and never fires for other entities or on respawn. Delivered to packs with the `combat` or `tick` hook. |

### Resource overrides (1.4)

A `.solixplugin` can contain an `assets/` folder laid out exactly like a resource pack (`assets/minecraft/textures/gui/widgets.png`,
`assets/minecraft/lang/en_us.json`, `assets/minecraft/sounds/...`, `assets/minecraft/textures/font/ascii.png`, `.png.mcmeta`
animation files, other namespaces too). Declare it in `plugin.json`:

```json
{ "id": "solix-look", "apiVersion": 1, "resources": { "kinds": ["gui"], "priority": 10 } }
```

- kinds: `all` (any path, like a full resource pack), `textures`, `gui` (`textures/gui/`), `fonts` (`font/`, `textures/font/`),
  `sounds` (`sounds/`, `sounds.json`), `lang`, `models`, `blockstates`, `shaders`, `texts`, `particles`. Files outside the
  declared kinds are ignored. `"resources": true` means `all`.
- While the plugin is enabled its assets are mounted as an always-on resource pack **above** the user's resource packs.
  Several plugin packs stack by `priority` (higher wins), then by id.
- Enabling, disabling, removing or installing the plugin reloads resources once (the loading overlay shows briefly).
- `entry` is optional for a resources-only pack. Encrypted packs (`SLXE`) work the same: assets are read after decryption,
  in memory only.
- `pack.png` comes from the pack `icon` if set.

### Themed vanilla bits (1.4)

With the vanilla skin on (Settings > Appearance), item tooltips and the tab list background now follow the active theme
(accent border, charcoal fill). Everything else that vanilla draws from textures (hotbar, hearts, widgets, containers) can
be reskinned with a `gui`/`textures` resource override.

## API 1.5 additions

Backward compatible. Feature-test with `(solix.apiMinor || 0) >= 5`. One general primitive: a post-process pipeline
that any shader plugin (colour grading, bloom-ish blur chains, CRT, the eagler-shaders presets) is built on.

| Addition | Hook | Details |
| --- | --- | --- |
| `solix.render.post.set(passes)` | `shaders` | Install your chain: `[{name, fragment: "shaders/grade.fsh", scale}]` (`fragment` = a file in your pack) or `{source: "glsl..."}` inline; a plain string is a fragment path. Up to 8 passes, 64 KB each. Passes run in order on the finished world image (after the hand, before the HUD/GUI); the last pass writes the screen. `scale` (0.0625..1) renders that pass at a fraction of the screen size (cheap blur chains). Replaces your previous chain; chains of several plugins run one after another in enable order. |
| `solix.render.post.uniform(name, value)` | `shaders` | Set a uniform on every pass of your chain: a number, `[x, y]`, `[x, y, z]`, `[x, y, z, w]`, a boolean (sent as int), or `{int: true, value: [..]}` for `int`/`ivecN`. Values persist until the chain is replaced. |
| `solix.render.post.uniforms(obj)` | `shaders` | Same, for every key of `obj`. Handy for presets: `uniforms({Saturation: 1.2, ENABLE_VIGNETTE: true})`. |
| `solix.render.post.clear()` | `shaders` | Remove your chain. Also happens when the plugin is disabled. |
| `shaderError` event | `shaders` | `solix.on("shaderError", msg => ...)`: your chain failed to compile/link (msg has the GL info log). The chain is dropped and the game renders without it; call `set` again with a fix. |

Writing shaders: use vanilla / OptiFine-style GLSL 1.20 fragment shaders. The client strips `#version` and `precision`,
maps `texture2D` and `gl_FragColor`, and turns any `varying vec2 <name>;` into the screen UV (0..1), so
`varying vec2 texCoord;` works as-is. `#include "util.glsl"` (and `#moj_import`) pulls in another file from your pack.
Code is compiled as GLSL ES (1.00 or 3.00 depending on the browser), so write float literals as `1.0`, not `1`.

Built-in uniforms (declare the ones you use): `sampler2D DiffuseSampler` (previous pass, or the scene for the first),
`sampler2D OriginalSampler` (the untouched scene), `vec2 InSize`, `vec2 OutSize`, `vec2 ScreenSize` (pixels), `float Time`
(seconds), `float DayTime` (0..1, 0 = sunrise), `float RainStrength` (0..1).

Safety: a pass only sees those two textures and your uniforms; there is no depth buffer, no world data and no way out
of the GPU program. If anything throws while rendering, plugin post-processing is switched off until restart. Players
can turn all plugin shaders off in **Settings > Video > Advanced > Plugin Shaders**.

Not done yet (documented, not shipped): sky and water programs (`gbuffers_skybasic`, `gbuffers_water`), depth/normal
buffers, shadow maps and OptiFine `shaders.properties` option screens. The 1.14 Eagler renderer draws terrain through
its own fixed shader set, so these need renderer surgery; plugin options are done with `solix.settings` + `uniform`.

Example: `plugins/eagler-shaders` ports the six NT9712/eagler-shaders presets (Apache-2.0) in about 15 lines of JS:

```js
var preset = solix.settings.choice("preset", "Preset", ["Noir", "Bright"], 0);
function apply() { var id = ["noir_low", "bright_low"][preset.get()];
  solix.render.post.set([{ name: id, fragment: id + ".fsh" }]); solix.render.post.uniforms(PRESETS[id]); }
solix.on("enable", apply); solix.on("settingChange", apply);
```

## API 1.6 additions

Backward compatible. Feature-test with `(solix.apiMinor || 0) >= 6`. One general screen-layout system, all behind the
`gui` hook. Coordinates are GUI pixels (the same units as vanilla slot positions); container callbacks get the
container's top-left as the origin, screen hooks get the screen's top-left.

| Addition | Details |
| --- | --- |
| `solix.gui.layout(ids, spec)` | Re-lay out container screens. `ids`: a screen id, a class name, an array of them, or `"*"` for every container screen. Returns `{remove()}`. Re-applied every time a screen opens or resizes (and on creative tab switches). Several layouts for one screen merge in enable order (later wins per field). |
| `spec.width`, `spec.height` | New screen size (vanilla `xSize`/`ySize`, e.g. 176x166); a number or `fn(info)`. Recentres the screen. `spec.offsetX/offsetY` nudge it. |
| `spec.slots` | Move or hide slots: `{index: {x, y}}`, `{index: false}` (hidden), an array, or `fn(slots, info)` returning either. `slots[i] = {i, x, y, inv: "player"/"container", index, empty, item}`. Moved slots are moved for real, so hover, clicks, drags and shift-clicks follow them; hidden slots can't be clicked. |
| `spec.title`, `spec.inventoryLabel` | `{x, y, color, shadow, hidden}` or `false` to hide. Covers every container title and the "Inventory" label. |
| `spec.background(g, ctx)` | Draw your own background with the draw ctx. When set, the vanilla texture is skipped unless `spec.vanillaBackground: true` (note: vanilla progress arrows / the player model live in that layer). |
| `spec.foreground(g, ctx)` | Draw over the slots and labels (under the cursor item and tooltips). |
| `spec.hover`, `spec.drag` | Colours of the hovered-slot highlight and the drag-split highlight (default `#80FFFFFF`). |
| `solix.gui.highlight({hover, drag})` | The same highlight colours for every container screen; a layout's own colours win. |
| `solix.gui.onDraw("pre" \| "post", fn(g, ctx), ids?)` | Draw before / after any screen (menus, chat, options, containers). `ids` defaults to `"any"`. Returns `{remove()}`. |
| `solix.gui.clearLayouts()` | Drop all of your layouts, draw hooks and highlights. |
| `g.glass(x, y, w, h, {radius, dim, tint, alpha, blur, cut})` | Frosted panel: a blurred copy of what is behind it (world + screen tint). The blur is taken once per frame, by the first glass panel, at 1/4..1/16 resolution, and shared by every panel after it; so `blur` (0.25..2) only counts on that first panel. `dim` 0..1 darkens it (0.8), `tint` is laid on top, `cut` uses the Solix cut corners. Also works in HUD elements. Falls back to flat translucent glass when the player has glass turned off. |

`ctx`: `{screen, cls, container, phase, width, height, mouseX, mouseY, xSize, ySize, left, top, partialTicks, theme, state, font}`
(`mouseX/Y` are relative to the origin). Screen ids are the class name without `Screen`, in snake case: `inventory`,
`creative`, `chest`, `shulker_box`, `crafting`, `furnace`, `blast_furnace`, `smoker`, `anvil`, `enchantment`,
`brewing_stand`, `beacon`, `grindstone`, `loom`, `stonecutter`, `cartography_table`, `merchant`, `horse_inventory`,
`hopper`, `dispenser`; menus are `main_menu`, `ingame_menu`, `chat`, `options`, ... (`solix.gui.screen` gives the class name).

Safety: layouts only move slots and draw through the draw ctx. A pack can't click, read other screens' text fields or
send packets, and positions are clamped. Errors count toward the usual 5-error auto-disable.

```js
solix.gui.layout("*", {
  vanillaBackground: false, title: { color: solix.theme.text }, hover: "#40FFFFFF",
  background: (g, c) => g.glass(0, 0, c.xSize, c.ySize, { radius: 6, tint: "#30101018", cut: true }),
  slots: s => s.map(x => ({ x: x.x, y: x.y + 2 }))
});
```

### Chat input masking + login vault (1.6)

| Addition | Hook | Details |
| --- | --- | --- |
| `solix.chat.input.mask({prefixes, char})` | `chat` or `vault` | While the chat box text starts with one of `prefixes` (e.g. `["/login", "/l", "/register", "/reg", "/changepassword"]`), every non-space character after the command is drawn as `char` (default `*`). Display only: the text that is sent is unchanged. `mask(null)` clears. Rules are dropped when the plugin is disabled, so set them in `solix.on("enable", ...)`. A function form is not supported (rules run client-side, no per-keystroke JS). |
| (always on) | | Messages starting with a masked prefix, or with `/login`, `/l`, `/register`, `/reg`, `/changepassword`, `/changepass`, `/cp`, are never added to the up-arrow chat history. Sent chat is never logged by the client. |
| `solix.vault.save(host?)` | `vault` | Opens a client-drawn "Save login for <host>" dialog (default host = the server you are on). The password goes into the client's vault, never to the plugin. |
| `solix.vault.has(host)`, `.hosts()` / `.list()` | `vault` | Which hosts have a saved login (host names only). |
| `solix.vault.remove(host)` | `vault` | Forget one saved login. |
| `solix.vault.autoLogin({host, trigger, command})` | `vault` | When a chat line matches `trigger` (a RegExp or Java-regex string, max 200 chars; default `/(login|l)\b`, case-insensitive) while you are connected to exactly `host` and a login is saved for it, the client sends `command` with `{pw}` replaced (default `/login {pw}`). screenshots/history; it is not protection against other code running in the same browser profile.

## API 1.7 additions

Backward compatible. Feature-test with `(solix.apiMinor || 0) >= 7`. 1.7 is about total conversions: a pack can restyle the game so nothing looks like Minecraft any more (fonts, item
icons, every HUD element), using a richer vector draw context.

### Pack fonts (1.7)

Declare faces in `plugin.json`. The `default` face replaces the vanilla pixel font **everywhere** the game's font
renderer draws (chat, every GUI, tooltips, HUD, item counts, signs, name tags), anti-aliased, kerned, colour codes kept.

```json
"font": { "default": "fonts/Rajdhani-SemiBold.ttf", "mono": "fonts/JetBrainsMono.otf", "scale": 1.0, "shadow": false }
```

* Files: `.ttf`, `.otf`, `.woff`, `.woff2` (rasterised once by the browser at 64 px into a mipmapped atlas, real
  kerning pairs for ASCII), a BMFont text `.fnt` + its page PNG, or a Solix atlas `.png` + `.txt` (the
  `tools/solix-assets` format). Paths are pack paths; `assets/` is tried as a prefix, then any file ending in the path.
* `scale` (0.5-2) multiplies the cap height (vanilla = 7 GUI px); `shadow: false` drops vanilla drop shadows.
* Strings with a character the face does not have fall back to the vanilla font for that string (so CJK chat still works).
* Every face is usable from the draw context: `g.text("AMMO", x, y, {font: "mono", size: 14})`, measured by
  `solix.util.textWidth(str, size, "mono")`. `solix.fonts.list()` / `solix.fonts.has(name)` tell you what loaded.
  When two enabled packs declare the same name the first one wins.

### Vector draw context (1.7)

All of these are batched into the same vertex stream as the rest of `g` and anti-aliased with a 1 physical-pixel fringe.
Points can be `[x, y, x, y, ...]`, `[[x, y], ...]` or `[{x, y}, ...]`.

| call | what |
| --- | --- |
| `g.shape(x, y, w, h, {radius, cut, fill, gradient: [top, bottom], stroke, strokeWidth})` | rounded or angled (`cut: true`) rect with fill/gradient and outline |
| `g.gradient(x, y, w, h, from, to, angle)` | `angle` in degrees (0 = left to right, 90 = top to bottom); omitted = vertical as before |
| `g.line(x0, y0, x1, y1, width, color)` | thick line |
| `g.polyline(points, width, color, closed)` | stroked path with round joins |
| `g.polygon(points, color)` | filled polygon, convex or concave (no holes) |
| `g.arc(cx, cy, r, a0, a1, width, color)` | stroked arc, radians, clockwise on screen |
| `g.pie(cx, cy, r, a0, a1, color, inner)` | filled sector, or a ring segment when `inner > 0` |
| `g.ring(cx, cy, r, width, color)` | full circle outline |
| `g.svg(d, x, y, size, color, {viewBox: 24, stroke: 0})` | SVG path icon (`d` attribute, any path incl. holes); rasterised by the browser once per size and cached; `stroke > 0` strokes instead of fills |
| `g.image(path, x, y, w, h, {tint, uv: [u0, v0, u1, v1]})` | a PNG from your pack at any resolution |
| `g.item("hotbar:N" \| "inv:N" \| "mainhand" ..., x, y, size)` | real item icons, now for hotbar and inventory slots too |

### Item icons (1.7)

* **Flat sprites via resources**: any resource pack (or a plugin pack with `"resources": ["textures"]`) can ship
  `assets/<namespace>/textures/solix/items/<item path>.png` (e.g. `assets/minecraft/textures/solix/items/diamond_sword.png`).
  It replaces that item's GUI icon (slots, hotbar, creative tabs, tooltips) with the image drawn into the 16x16 slot box.
  Any resolution works, no 16x16 limit. Reloaded with resources (F3+T).
* **`solix.gui.itemRenderer(fn, {ids}?)`** (`gui` hook): `fn(g, ctx)` draws in the 16x16 slot box (`ctx`: `id count
  damage maxDamage enchanted name size`). Return `true` to replace the icon; otherwise what you drew goes behind it
  (rarity glow etc.). `ids` limits the call to those items (cheaper). `itemRenderer(null)` removes it.
  Count and durability overlays stay vanilla (and use the pack font).

### HUD replacement (1.7)

`solix.hud.replace(id, fn, {vanilla: false})` (`hud` hook) hides a vanilla HUD element and calls `fn(g, ctx)` each frame
instead. `ctx.width/height` = GUI size, coordinates are GUI pixels over the whole screen, `ctx.data` = what vanilla would
have drawn. `fn = null` only hides it; `{vanilla: true}` keeps vanilla and draws on top. `hud.restore(id)` undoes it.
Returns a handle with `remove()`.

| id | `ctx.data` |
| --- | --- |
| `hotbar` | `{selected, offhand}` (use `g.item("hotbar:N", ...)` for icons) |
| `health` | `{health, max, absorption, hardcore, poison, wither, regen, hurtTime}` |
| `hunger` | `{food, saturation, hungerEffect}` |
| `armor` | `{value}` |
| `air` | `{air, max, underwater}` |
| `xp` | `{level, progress, total}` |
| `mount` | `{health, max, jump}` (horse health + jump bar) |
| `crosshair` | null |
| `bossbar` | `[{name, progress, color, overlay}]` |
| `scoreboard` | `{title, lines: [{name, score}]}` (sidebar) |
| `tablist` | `{visible, players: [{name, ping}]}` |
| `chat` | `{open, lines: [{text, age}]}` (newest first, age in ticks; the chat input box itself stays vanilla) |
| `actionbar` | `{text, time}` |
| `title` | `{title, subtitle, time}` |
| `selected` | `{name, time}` (held item name popup) |
| `effects` | null (potion icons; read `solix.player.effects`) |
| `toast` | `[{type, title, description, icon?, progress, age, visibility}]` — active vanilla toasts (`tutorial` / `advancement` / `recipe` / `system` / `friend`); `icon` is an item id when the toast has one; `progress` is 0..1; `age` is ms on screen; `visibility` is `"show"` / `"hide"`. The plugin draws all of them; `fn = null` hides them. |
| `debug` | `{fps, x, y, z, facing, biome, chunks, f3Open, lines}` — Solix top-left FPS/XYZ overlay plus the F3 screen when open; `lines` is string[] (FPS/XYZ when F3 is closed, full F3 left column when open); `chunks` is the world-renderer debug string. |


All replaced elements share one host call per frame and draw after the vanilla HUD, before plugin HUD elements.
